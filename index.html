How PPM Defines LOD

The PPM LOD Framework

Our LOD framework follows the AIA / BIMForum LOD Specification principles, adapted for existing conditions modeling. Because PPM models existing conditions rather than design intent, these standards are applied to define the level of geometry and detail included based on what is visible, verifiable, and within the project scope.

Our standard deliverable is LOD 250 — a PPM-defined tier, not a formally defined AIA level. It sits between LOD 200 and LOD 300: some elements align more closely with one, some with the other, and many fall in between. This provides a practical benchmark that balances model usability, geometric development, and production efficiency.

LOD terminology is not applied consistently across the industry, and some external organizations use their own definitions of LOD 250. Those definitions do not govern PPM deliverables. The PPM LOD matrix and the project scope of work define the requirements and inclusions for each PPM LOD tier.

LOD vs. LOA

Level of Development (LOD) and Level of Accuracy (LOA) describe two different aspects of a model.

LOD defines the level of geometric development and detail included in modeled elements. LOA defines how closely the modeled geometry represents measured field conditions. These are established independently, meaning a highly detailed element is not necessarily more accurate.

Unless otherwise noted in the project scope, PPM Scan-to-BIM deliverables are produced to a target represented accuracy of ±1 inch relative to visible, accessible, and adequately field-documented existing conditions. This target is generally aligned with USIBD LOA 20.
